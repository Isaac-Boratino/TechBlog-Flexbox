# Flexbox: Projeto Escolar - Etec Boituva
## Descrição
Projeto escolar para aprendizado do css e html.
## Pontos Aprendidos:
### HTML
- ```<div>```: Estruturar atributos para classificar as div (#id e .class) e que ela é uma tag semântica; ou seja, ela separa os blocos de código.
- **#id:** Só pode ser usado usado uma vez e serve para identificar.
- **.class:** Pode ser usado várias vezes e serve para classificar.
### CSS
- **Flexbox:** Permite formatar alinhamento de containers através de eixos de dimensões. Tem atributos para alinhar, como ```justify-content, align-items, gap, etc.```
- **// RESET:** Método para resetar a estilização de páginas.
- **Pseudo-elementos:** Um parte específica de um seletor. Temos exemplos como ```::before, ::after``` e ```:hover, :last-child```
